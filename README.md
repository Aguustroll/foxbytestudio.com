# foxbytestudio.com
FOXBYTE STUDIO presenta la comunidad de jugadores de VOID FIGHTERS: La Falla del Vacío.  Acá no solo jugás: compartís opiniones reales, subís capturas de batalla, participás en retos diarios, te sumás a eventos y hasta podés agregar tus propios videojuegos para que otros los prueben.  Un juego. Una comunidad. Una historia que evoluciona con vos.
